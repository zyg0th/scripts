# Scripts

My personal script collection

| Script | Description |
|--------|-------------|
| get_last_screenshot.sh | downloads the last N screenshots from Android (via ADB) or iPhone via SSH. |
| get_apk.sh | downloads one or more apps by their package. |
| extract_shared_prefs.sh | extracts shared_prefs from a connected Android device via adb. |
| set_android_proxy.sh | Redirect a connected Android device's HTTP/HTTPS traffic to an external. |
